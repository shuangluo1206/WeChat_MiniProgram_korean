## 🏷️ 词源分类

### 词源分布

| 词源类型 | 说明 | 特点 | 数量占比 |
|---------|------|------|---------|
| **汉字词** (hanja) | 来自汉语的词汇 | 标注对应汉字 | ~55% |
| **固有词** (native) | 纯韩语词汇 | 韩民族原生词 | ~30% |
| **外来语** (loanword) | 英语等外语 | 标注原词和来源 | ~15% |

### 示例

**汉字词**:
```json

  "korean": "학교",

  "etymology": "學校",
  "sourceLanguage": "chinese"
}
```

## 🚀 使用方法

### 导入到云数据库

1. 上传云函数 `importWords`
2. 打开 `pages/import/import` 页面
3. 点击"批量导入词汇"
4. 选择"智能导入（跳过重复）"
5. 等待导入完成（约15-20秒）

### 预期结果

- 原有词汇保留
- 新词自动去重
- 约导入140+个新词（部分可能重复）
